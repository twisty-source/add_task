# Блог публикаций (Blog)

Веб-приложение на **Django** с интерфейсом на **Bootstrap 4** для публикации и чтения авторских статей с разграничением прав доступа.

---

## 🛠 Стек технологий

- **Язык**: Python 3.10+ / 3.12
- **Фреймворк**: Django 5.x
- **Статика**: WhiteNoise
- **WSGI-сервер**: Gunicorn
- **База данных**: SQLite (хранится в постоянном томе Docker)
- **Контейнеризация**: Docker & Docker Compose

## Реализованный функционал

1. **Модель `BlogPost`**:
   - `title` — заголовок публикации (до 200 символов);
   - `text` — подробный текст статьи;
   - `date_added` — дата и время публикации (автоматически при создании);
   - `owner` — автор публикации (`ForeignKey` на модель `User`).

2. **Публичный доступ и права авторов**:
   - Чтение публикаций доступно **всем посетителям** без обязательного входа;
   - На главной странице все публикации выводятся в обратном хронологическом порядке (самые свежие — первыми);
   - Создание публикаций доступно только зарегистрированным авторам (`@login_required`);
   - Редактировать и удалять статью может **только её непосредственный автор**;
   - При попытке чужого пользователя или анонима отредактировать статью возвращается ошибка **404 Not Found** (`get_object_or_404(BlogPost, id=post_id, owner=request.user)`);
   - Подбор несуществующего ID возвращает **404** вместо ошибки 500;
   - Безопасный выход из системы через POST-запрос с CSRF-токеном.

3. **Административная панель**:
   - Настроен `BlogPostAdmin`: список записей, поиск по заголовку и тексту, фильтрация по автору и дате.

## Локальный запуск (для разработки)

1. Клонируйте проект и перейдите в папку `blog`:
   ```bash
   cd blog
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv blog_env
   source blog_env/bin/activate   # Linux/macOS
   # или .\blog_env\Scripts\activate на Windows
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Примените миграции:
   ```bash
   python manage.py migrate
   ```

5. Создайте администратора:
   ```bash
   python manage.py createsuperuser
   ```

6. Запустите сервер разработки:
   ```bash
   python manage.py runserver
   ```
   Приложение откроется по адресу: `http://127.0.0.1:8000/`.

7. Запуск тестов:
   ```bash
   python manage.py test
   ```

## 🚀 Развёртывание через Docker Compose

1. Создайте файл `.env`:
   ```bash
   cp .env.example .env
   ```

2. Соберите и запустите контейнеры:
   ```bash
   docker compose up -d --build
   ```

3. Создайте суперпользователя в контейнере:
   ```bash
   docker compose exec web python manage.py createsuperuser
   ```
